# 혜택 캘린더 (BenefitCal) 로컬 개발 가이드

> 목적: MVP 로컬 개발 환경을 빠르게 구성하기 위한 최소 가이드.

## 1) 필수 환경
- Node.js 24 LTS 이상
- pnpm 9.15.0 이상
- Docker Desktop (PostgreSQL, Redis 컨테이너 실행용)

## 2) 프로젝트 구조

```
Benefit_Calendar/          # Turborepo 모노레포 루트
├── apps/
│   ├── web/               # Next.js 프론트엔드 (포트 3000)
│   └── api/               # NestJS 백엔드 API (포트 4000)
├── packages/
│   ├── shared-types/      # 공유 타입 정의
│   ├── shared-utils/      # 공유 유틸리티
│   └── eslint-config/     # ESLint 설정
├── docker-compose.yml     # PostgreSQL 16 + Redis 7
├── turbo.json             # Turborepo 설정
└── pnpm-workspace.yaml    # pnpm 워크스페이스 설정
```

## 3) 초기 설정

### 3.1 Docker 컨테이너 기동
```bash
docker compose up -d
```
- PostgreSQL 16 (alpine): `localhost:5432`
  - DB: `benefit_calendar`, User: `benefit_user`, Password: `benefit_pass`
- Redis 7 (alpine): `localhost:6379`

컨테이너 상태 확인:
```bash
docker compose ps
```

### 3.2 의존성 설치
```bash
pnpm install
```

### 3.3 환경 변수 설정
`apps/api/.env.local` 파일이 이미 존재합니다. 내용 확인:

```env
DATABASE_URL=postgresql://benefit_user:benefit_pass@localhost:5432/benefit_calendar
REDIS_URL=redis://localhost:6379
AUTH_JWT_SECRET=dev-secret-key-do-not-use-in-production
AUTH_JWT_EXPIRES_IN=15m
AUTH_REFRESH_EXPIRES_IN=7d
PORT=4000
```

> Prisma CLI는 `.env` 파일만 자동 로드합니다. DB 마이그레이션 실행 시 `apps/api/.env` 파일이 필요합니다. `.env.local`을 복사하여 사용합니다:
> ```bash
> cp apps/api/.env.local apps/api/.env
> ```

### 3.4 DB 초기화 (Prisma)
```bash
# Prisma Client 생성
pnpm db:generate

# 마이그레이션 실행
pnpm db:migrate

# 시드 데이터 삽입 (테스트 사용자 1명 + 혜택 10건)
pnpm db:seed
```

시드 데이터:
- 테스트 사용자: `test@benefitcal.com` / `password123`
- 혜택 10건 (7개 카테고리: 주거, 교통, 문화, 창업, 생활, 교육, 의료)

## 4) 개발 서버 실행
```bash
pnpm dev
```
- 프론트엔드 (Next.js): `http://localhost:3000`
- 백엔드 API (NestJS): `http://localhost:4000`
- Swagger UI: `http://localhost:4000/api/docs`

## 5) 주요 명령어

| 명령어 | 설명 |
|--------|------|
| `pnpm dev` | 전체 개발 서버 실행 (web + api) |
| `pnpm build` | 전체 빌드 |
| `pnpm db:generate` | Prisma Client 생성 |
| `pnpm db:migrate` | DB 마이그레이션 실행 |
| `pnpm db:seed` | 시드 데이터 삽입 |
| `docker compose up -d` | Docker 컨테이너 기동 |
| `docker compose down` | Docker 컨테이너 중지 |

## 6) API 엔드포인트 (13개)

Base URL: `/api/v1`

| # | Method | Path | 인증 | 설명 |
|---|--------|------|:----:|------|
| 1 | POST | /auth/register | - | 회원가입 |
| 2 | POST | /auth/login | - | 로그인 (JWT 발급) |
| 3 | GET | /users/me | JWT | 내 프로필 조회 |
| 4 | PATCH | /users/me | JWT | 내 프로필 수정 |
| 5 | GET | /benefits | - | 혜택 목록 조회 |
| 6 | GET | /benefits/:id | - | 혜택 상세 조회 |
| 7 | POST | /users/me/benefits/:id/bookmark | JWT | 북마크 토글 |
| 8 | GET | /users/me/benefits | JWT | 내 혜택 목록 |
| 9 | PATCH | /users/me/benefits/:id | JWT | 내 혜택 상태 변경 |
| 10 | GET | /users/me/notifications | JWT | 알림 설정 조회 |
| 11 | PATCH | /users/me/notifications | JWT | 알림 설정 변경 |
| 12 | GET | /dashboard/summary | JWT | 대시보드 요약 |
| 13 | GET | /health | - | 헬스체크 |
