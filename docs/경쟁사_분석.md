# Benefit Calendar - 경쟁 서비스 분석 보고서

> 작성일: 2026-03-22
> 프로젝트: Benefit Calendar (청년/자영업자 대상 정부 혜택 캘린더 서비스)

---

## Executive Summary

**핵심 발견 5가지:**

1. **한국 정부 혜택 정보 시장은 심각하게 파편화되어 있다.** 정부24, 복지로, 온통청년, 중소벤처24, 소상공인24, 비즈인포 등 6개 이상의 공식 포털이 서로 다른 대상/목적으로 분산 운영되며, 개인이 자신에게 맞는 포털을 찾는 것 자체가 진입 장벽이다.

2. **마감일 캘린더 관리 기능은 사실상 공백 지대다.** 현존 서비스들은 혜택 정보 "검색"에 집중하고 있으며, 마감일을 개인 캘린더에 등록하거나 추적하는 기능은 거의 없다. 창업자 대상 서비스(커넥트웍스, 서울창업캘린더)에서 일부 캘린더 기능이 등장하지만 일반 청년/자영업자 대상은 아니다.

3. **카카오뱅크 "정부지원금 찾기"(2025년 9월 출시)가 가장 가까운 경쟁자다.** 출시 50일 만에 50만 명을 돌파했으나, 은행 서비스와의 종속 관계, 캘린더 관리 기능 부재, 신청 상태 추적 미지원이 약점이다.

4. **정부 공식 앱의 UX는 심각하게 낮은 평가를 받고 있다.** 정부24 앱의 구글 플레이 평점은 1.5점(5점 만점)이며, 학술 연구에서 사이트 작동, UI 문제, 인증 복잡성이 주요 불만으로 추출되었다. 이 불만이 민간 서비스의 시장 기회다.

5. **민간 서비스(삼쩜삼)의 성공 공식이 검증되어 있다.** 삼쩜삼은 "숨은 환급금"을 찾아주는 단순한 개념으로 2,000만 명 가입, 누적 환급액 8,000억 원 규모를 달성했다. "모르면 손해" 심리를 자극하는 가치 제안이 핵심이다.

## 1. 한국 내 유사 서비스 분석

### 1-1. 정부 공식 포털

#### A. 정부24 / 보조금24

- **URL**: https://www.gov.kr | https://www.gov.kr/portal/rcvfvrSvc/main
- **운영 주체**: 행정안전부
- **타겟 유저**: 전 국민 (연령/직업 무관)
- **핵심 기능**:
  - 중앙부처, 지자체, 공공기관, 교육청 총 1만여 개 서비스 조회
  - 주민등록번호 기반 자격정보 연계로 맞춤 혜택 안내
  - 나와 가족이 받을 수 있는 혜택을 원클릭 조회
  - 취업, 건강, 임신 등 12개 카테고리 분류
  - 위치 기반 시설(어린이집, 청소년 센터 등) 검색
- **캘린더/마감일 관리**: 미지원. 혜택 목록 제공에 그침.
- **개인화/추천 기능**: 본인 인증 후 공공 마이데이터 연계를 통한 맞춤 안내(수동 조회 방식)
- **UI/UX 특징**: 정보 과부하 문제. 기관 중심 정보 구조로 사용자 관점 흐름이 약함.
- **앱 평점**: 구글 플레이 **1.5점** (5점 만점). 증명서 발급 오류, UI 혼란, 인증 복잡성이 7대 불만 토픽.
- **사용자 규모**: 국민비서(행안부 운영) 2022년 기준 1,500만 가입.

#### B. 복지로 (Bokjiro)

- **URL**: https://www.bokjiro.go.kr
- **운영 주체**: 보건복지부
- **타겟 유저**: 복지 혜택 대상자 (고령층, 저소득층 비중 높음)
- **핵심 기능**:
  - 복지멤버십: 개인 자격 정보 등록 후 맞춤 혜택 정기 알림
  - 2024년 기준 총 128종 서비스(중앙부처 83종 + 지자체 45종) 맞춤 안내
  - 온라인 신청 (기초생활보장, 기초연금 등 주요 서비스)
- **캘린더/마감일 관리**: 미지원
- **개인화/추천 기능**: 복지멤버십 가입 후 맞춤 안내 수신 (Push/문자). 수동 가입 필요.
- **사용자 규모**: 복지멤버십 가입자 **1,112만 명** (2024년 12월)

#### C. 온통청년 (Youth Center)

- **URL**: https://www.youthcenter.go.kr
- **운영 주체**: 고용노동부 (운영: 한국청년재단)
- **타겟 유저**: 만 19~34세 청년
- **핵심 기능**:
  - 중앙부처 + 17개 시도 지자체 청년 사업 **3,000여 개** 검색
  - AI 챗봇 기반 정책 탐색 (대화형 UX)
  - 신청자격 자가진단 (공공마이데이터 연계, 서류 없이 자가 확인)
  - 17개 시도 청년정책플랫폼 + 237개 청년센터 연결
  - 간편인증, 카카오/네이버 민간 ID 지원
- **캘린더/마감일 관리**: 미지원 (마감일 표시는 있으나 개인 캘린더 등록 불가)
- **개인화/추천 기능**: AI 챗봇 + 지역/관심 분야 기반 필터링

#### D. 청년몽땅정보통 (서울시)

- **URL**: https://youth.seoul.go.kr
- **운영 주체**: 서울특별시
- **타겟 유저**: 서울 거주 청년
- **핵심 기능**:
  - 서울시 + 중앙정부 약 2,000개 청년정책 통합 제공
  - **정책캘린더**: 월별 주요 청년정책 일정 확인 (주목할 만한 점)
  - AI 추천 서비스: 관심 분야 기반 정책 추천
  - 정책통합신청: 온라인 원스톱 신청
  - 청년공간지도: 서울 내 청년 전용 공간 지도 검색
- **캘린더/마감일 관리**: 정책캘린더 기능 있음. 단, **개인 일정과 동기화 불가**. 공통 일정 뷰어에 불과.

### 1-2. 핀테크/민간 서비스

#### E. 카카오뱅크 "정부지원금 찾기" (가장 근접한 경쟁자)

- **URL**: https://www.kakaobank.com/products/governmentGrantMatch
- **출시**: 2025년 9월
- **타겟 유저**: 카카오뱅크 입출금 계좌 보유 개인 (만 14세 이상)
- **핵심 기능**:
  - 챗봇 대화형 프로필 등록 (기초 정보 입력)
  - 스크래핑 기반 자동 정보 수집
  - 맞춤 지원금 추천 목록 제공
  - 관심 지원금 등록 (최대 20개) + 알림
  - 카카오뱅크 자체 서비스(K-패스, 보금자리론 등)와 직접 연계
- **캘린더/마감일 관리**: 미지원
- **신청 상태 추적**: 미지원
- **사용자 규모**: 출시 50일 만에 **50만 명** 돌파, 일평균 1만 명 이상 신규 가입
- **약점**: 카카오뱅크 계좌 종속, 캘린더 없음, 상태 추적 없음, 은행 앱 내 부가 기능

#### F. 토스 "숨은 정부지원금 찾기" (서비스 종료)

- **서비스 종료**: 2024년 8월
- 민간 최초로 정부24 보조금24 API를 자체 앱에서 구현
- 300여 개 정부 혜택 + 600여 개 지자체 지원사업 제공
- 토스 2,000만 명 기반 위에서도 서비스를 지속하지 않음
- **시사점**: 수익화 모델 없이 정보 서비스만으로는 대형 핀테크도 지속 불가

#### G. 삼쩜삼 (3o3) - 수익화 성공 참조 모델

- **URL**: https://www.3o3.co.kr
- **운영 주체**: 자비스앤빌런즈
- **타겟 유저**: 프리랜서, 자영업자, 직장인 (종합소득세 신고 대상자)
- **핵심 기능**: 국세청 데이터 연동 환급 자동 계산, 원클릭 환급 신청
- **수익 모델**: 환급금의 10~20% 수수료 (성과 기반) + 세무사 연결 광고
- **사용자 규모**:
  - 누적 가입자: **2,000만 명**
  - MAU: **660만 명** (2022.12, 전년 대비 40% 성장)
  - 누적 환급 신고: **1,000만 건**
  - 누적 환급액: **8,000억 원**
- **시사점**: "모르면 손해" 심리 + 성과 기반 수수료 = 검증된 수익화 공식

#### H. 국민비서 "구삐"

- **URL**: https://www.ips.go.kr/pot
- **운영 주체**: 행정안전부
- **핵심 기능**: 카카오톡, 네이버앱, 토스, KB스타뱅킹 등 17개 민간 앱으로 행정 알림 수신
- **사용자 규모**: 2022년 기준 **1,500만 명** 가입
- **캘린더/마감일 관리**: 알림 수신 가능하나 캘린더 형태 관리 불가

### 1-3. 창업/소상공인 특화 서비스

#### I. 커넥트웍스 (Connect Works) - 컨셉 가장 유사

- **URL**: https://works.connect24.kr
- **서비스 성격**: 스타트업/기업 대상 정부지원사업 통합 안내 서비스
- **데이터 규모**: 2025년 기준 **15,688개 사업**, 총 사업금액 약 **107조 7,450억 원**
- **핵심 기능**: 정부지원사업 캘린더형/목록형 제공, 스크랩 관리, 태그 검색
- **캘린더/마감일 관리**: 캘린더형 UI 제공 (단, 개인 캘린더 동기화 없음)
- **AI 고도화**: 2026년 3월 업데이트 예정
- **핵심 차이**: 타겟이 "창업 담당자/기업 관계자"이며 B2B 성격. 일반 청년에게는 정보량 과부하 및 전문 용어 장벽.

#### J. 중소벤처24 "사업공고 캘린더"

- **URL**: https://www.smes.go.kr/main/pblancCalendar
- **운영 주체**: 중소벤처기업부
- 사업공고, 접수 시작일, 마감일 캘린더 형태 제공 (개인화 없음)

#### K. 서울창업캘린더

- **URL**: https://www.s-calendar.kr
- 서울 소재 창업지원사업 일정 캘린더형 표시 (개인화 및 알림 기능 없음)

#### L. 비즈인포 (Bizinfo)

- **URL**: https://www.bizinfo.go.kr
- **운영 주체**: 중소벤처기업진흥공단
- 중소기업 지원사업 정보 통합 (목록형만 제공, 캘린더 없음)

#### M. kfund.ai

- **URL**: https://kfund.ai
- AI 기반 정부 지원사업 알리미. 구독 모델 추정.

## 2. 해외 유사 서비스 분석

### A. USAGov Benefit Finder (미국)

- **URL**: https://www.usa.gov/benefit-finder
- 2024년 9월 Benefits.gov 종료 후 USA.gov로 통합
- 1,000개 이상 정부 지원 프로그램, 설문 기반 매칭
- 캘린더/상태 추적 없음

### B. BenefitsCheckUp (미국)

- **URL**: https://benefitscheckup.org
- **운영 주체**: NCOA (비영리), 2001년 출시
- **타겟**: 55세 이상 저소득 노인
- 2024년 **130만 명** 지원, 추정 혜택 가치 **6억 2,000만 달러**
- **시사점**: 미국에서도 적격자의 SNAP 수급률은 30%에 불과. 정보 격차는 한국과 동일.

### C. Turn2us Benefits Calculator (영국)

- **URL**: https://benefits-calculator.turn2us.org.uk
- GOV.UK가 공식 추천하는 민간 자선단체 서비스
- 연 10회 무료, 이후 유료 업그레이드
- **수익 모델**: 자선 기부 + 기관 라이선스

### D. entitledto (영국) - B2B 수익화 모델 참조

- **URL**: https://www.entitledto.co.uk
- 지방정부 웹사이트에 임베드 형태로 API 라이선스 판매
- **수익 모델**: B2B SaaS (API 라이선스)
- **시사점**: 한국 지자체 청년 플랫폼 대상 B2B 판매 경로 검토 가능

### E. myGov (호주) - 선진 모델

- **URL**: https://my.gov.au
- 일 평균 **100만 건 이상** 로그인
- Medicare, Centrelink, ATO 등 단일 로그인 통합
- **"생애주기 이벤트" 기능**: 결혼, 출산, 취업 등 생애 이벤트 등록 시 관련 서비스 자동 안내
- **시사점**: Benefit Calendar가 장기적으로 지향할 수 있는 참조 아키텍처

### F. Grants.gov (미국)

- **URL**: https://www.grants.gov
- 연방 지원금 신청 통합 포털 (주로 기관/단체 대상)
- 신청 상태 추적(Track My Application) 기능 제공

## 3. 차별화 포인트 분석

### 기존 서비스들의 5가지 공통 약점

| # | 약점 | 상세 |
|---|------|------|
| 1 | **캘린더/마감일 관리 부재** | 모든 서비스가 혜택 "검색"에서 멈춤. 개인 캘린더 등록, D-day 알림, 상태 추적 없음 |
| 2 | **분산 포털 탐색 피로** | 청년이자 자영업자인 사람은 온통청년+소상공인24+중소벤처24 각각 방문 필요 |
| 3 | **낮은 UX 완성도** | 정부24 앱 평점 1.5점. UI 혼란, 인증 복잡성 불만 2021~2023 증가 추세 |
| 4 | **신청 상태 추적 없음** | 발견 이후의 관리 영역 전체가 공백 |
| 5 | **청년/자영업자 복합 수요 미충족** | 두 카테고리를 동시에 다루는 서비스 없음 |

### Benefit Calendar 차별화 포인트

| 차별화 요소 | 현존 서비스 | Benefit Calendar |
|-------------|------------|------------------|
| 마감일 캘린더 관리 | 거의 없음 | **핵심 기능** |
| 신청 상태 추적 | 없음 | 북마크 -> 준비 -> 완료 -> 수령 워크플로 |
| 청년+자영업자 통합 | 분산 포털 | 단일 플랫폼 |
| 개인화 추천 | 수동 조회 중심 | 프로필 기반 자동 추천 |
| AI 추천 | 제한적 (챗봇 수준) | AI 기반 맞춤 추천 |
| UX 완성도 | 낮음 (정부 서비스) | 현대적 카드형 UX |
| 특정 앱 종속 | 카카오뱅크 계좌 필요 등 | 독립 서비스 |

### 시장 기회

1. **"발견 + 관리" 통합 니즈**: 삼쩜삼이 "환급금 발견 -> 신청 대행"까지 통합해 성공한 것처럼, "혜택 발견 -> 수령 완료"까지의 전체 여정 관리
2. **청년/자영업자 복합 타겟**: 두 카테고리 통합하는 단일 창구 자체가 차별점
3. **정부 예산 확대 추세**: 2026년 창업/소상공인 지원사업 예산 약 3.4조 원
4. **수익화 경로가 검증된 시장**: 삼쩜삼(수수료), 커넥트웍스(구독), entitledto(B2B API)

## 5. 주요 경쟁 리스크

1. **카카오뱅크가 캘린더 기능을 추가하면**: 브랜드/배포력에서 압도적 열세. 빠른 기능 선점 필요.
2. **정부가 서비스를 통합하면**: 정부24나 복지로가 캘린더 기능 추가 시. 다만 정부 서비스 UX 개선 속도는 매우 느림.
3. **수익화 모델 부재**: 토스 서비스 종료 사례. 무료로만 운영하면 지속 불가.
