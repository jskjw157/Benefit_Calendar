# 혜택 캘린더 (BenefitCal) MVP 프론트/백엔드 작업 분해 체크리스트

## 3) 백엔드 체크리스트

### 3.1 프로젝트 기반 구성
- [x] 프로젝트 구조/환경 설정 → Turborepo 모노레포 + NestJS
- [x] 인증(JWT) 기본 구현 → AuthModule (register, login, JwtGuard)
- [x] 에러 핸들링/유효성 검사 체계 구축 → HttpExceptionFilter + ValidationPipe

### 3.2 인증/사용자
- [x] 로그인 API (JWT 발급) → POST /auth/login + /auth/register
- [x] 사용자 프로필 조회/수정 API → GET/PATCH /users/me
- [x] 사용자 스키마 및 마이그레이션 → users 테이블 12 컬럼

### 3.3 혜택 데이터
- [x] Benefit 스키마 및 마이그레이션 → benefits 테이블 14 컬럼
- [x] 혜택 목록 API (검색/필터/정렬/페이징) → GET /benefits
- [x] 혜택 상세 API → GET /benefits/:id
- [x] 신청 가능 상태 계산 로직 → deadline 기준 파생
- [x] 샘플 데이터 시드 스크립트 → Prisma seed (10건)

### 3.4 사용자-혜택(UserBenefit)
- [x] UserBenefit 스키마 및 마이그레이션 → user_benefits 복합 PK
- [x] 내 혜택 목록 API (상태 필터) → GET /users/me/benefits
- [x] 북마크 추가/해제 API → POST /users/me/benefits/:id/bookmark (토글)
- [x] 상태 변경 API → PATCH /users/me/benefits/:id

### 3.5 알림
- [x] 알림 설정 조회/수정 API → GET/PATCH /users/me/notifications
- [ ] 마감 임박 알림 배치 스케줄러(일 1회)
- [ ] 이메일 발송 모듈(초기 1채널)
- [ ] 알림 발송 로그/기록 저장

### 3.6 대시보드
- [x] 요약 통계 API (매칭/마감 임박/신청 완료) → GET /dashboard/summary
- [ ] 성능 점검(목록 조회 성능 최적화)

### 3.7 운영/품질
